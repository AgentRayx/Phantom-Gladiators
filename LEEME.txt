PHANTOM GLADIATORS - PAGINA PARA GITHUB PAGES
=============================================

CONTENIDO
  index.html      pagina principal
  style.css       estilos
  script.js       descarga + efecto de espiritus (aqui editas tu usuario)
  img/            capturas de ejemplo (reemplazalas por las tuyas)
  .nojekyll       evita que GitHub procese la pagina con Jekyll

PASOS
1. Descomprime el zip y sube TODO el contenido de la carpeta al repositorio
   (incluido .nojekyll y la carpeta img).
2. Abre script.js y cambia en las primeras lineas:
     USUARIO      -> tu usuario de GitHub
     REPOSITORIO  -> el nombre de tu repositorio
     ARCHIVO      -> el nombre exacto de tu .exe
     ARCHIVO_DLC  -> el nombre exacto del .exe del DLC
3. En el repo: Releases > Create a new release > tag v1.0
   Adjunta tu instalador (con el mismo nombre que pusiste en ARCHIVO)
   adjunta tambien el .exe del DLC y pulsa Publish release.
4. Settings > Pages > Deploy from a branch > main / (root) > Save.
5. Tu pagina quedara en:
     https://TU_USUARIO.github.io/NOMBRE_DEL_REPO/

PARA CAMBIAR LAS CAPTURAS
  Guarda tus imagenes en img/ como captura1.jpg, captura2.jpg, captura3.jpg
  y en index.html cambia ".svg" por ".jpg" en la seccion Capturas.
